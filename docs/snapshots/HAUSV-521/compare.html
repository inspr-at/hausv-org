HAUSV-521: Hausüberblick Rebuild – Stufe 2

Zielsetzung: HTML-Rebuild des Hausüberblicks mit zwei Dichte-Fassungen – dicht für Verwalter/Admin, ruhig für Eigentümer/Beirat/Bewohner – plus eine mobile Komposition.

Status: Draft – nur HTML + PNG. Keine TEMPL-Integration, keine live-CSS-Änderung, kein Deployment.

Technische Entscheidungen:

  • Tokens ausschließlich aus internal/web/web.go – keine neuen Farben, Radien oder Schatten
  • Reale deutsche/österreichische WEG-Texte – kein Lorem Ipsum
  • Gleiche Daten in beiden Fassungen – nur Darstellungsdichte unterscheidet sich
  • Genehmigte Chrome-Elemente: Full-width Hero + Hairline, flush Sidebar Map, quiet Portal Dropdown, Rolle im Account Footer

Fassung: Dicht (Dense)

Für Verwalter / Admin

Kennzahlenzeile im Hero, vollständige Anliegen-Tabelle mit Status, Betreff, Beschreibung, Ort, Alter und Zuständigkeit. Termine und Aushang als kompakte Cards in der Seitenspalte. Energie-Status als horizontaler Strip. Alles auf einen Blick.

Desktop (1440 × 900)

Kernelemente

  • Hero: Begrüßung "Hallo Frau Bachmeier" + Datum + 3 Metriken (Anliegen, Termine, Aushang) + "Anliegen melden" Button
  • Anliegen-Tabelle: 6 Spalten, Status-Dots (gold = Neu, green = In Arbeit), Beschreibung gekürzt, Ort mit Zeilenumbruch, Alter mit Überfällig-Markierung
  • Termine (Side): Nächste 2 Termine mit Datums-Chip (Tag + Monat), Titel, Uhrzeit, Ort
  • Aushang (Side): 3 Einträge mit Dot (gold = ungelesen), Titel, Kategorie, Zeitstempel
  • Energie-Strip: Hausname + Status-Text + "Details anzeigen" Link
  • Utility Links: Kontakte, Dokumente, Abstimmungen, Parking, Übergaben, Benutzer & Rechte, Verlauf, Einstellungen, Hilfe
📄 HTML 🖼️ PNG

Fassung: Ruhig (Quiet)

Für Eigentümer / Beirat / Bewohner

Ein Satz beantwortet: "Betrifft mich etwas?" – dann Accordion-Module, die bei Bedarf öffnen. Anliegen, Termine und Aushang in kollabsierbaren Boxen. Energie-Status als dezenter Fußzeilenlink. Ruhiger Einstieg statt dichte Info-Wand.

Desktop (1440 × 900)

Kernelemente

  • Hero: Begrüßung "Hallo Herr Bauer" + Datum – keine Metriken-Zeile
  • Answer: Großer Satz "Drei Dinge warten auf Sie" (dynamisch: 0, 1, 2 oder 3)
  • Anliegen-Modul: Kollabierbar, Zusammenfassung "3 offen", beim Öffnen reduzierte Zeilen (Betreff, Ort, Alter), mehr als 3 → "Alle anzeigen" Details
  • Termine-Modul: Grüner Dot, "2 Termine", Datums-Badge + Titel + Uhrzeit + Ort
  • Aushang-Modul: Grauer Dot (gold bei ungelesen), "1 neue Beiträge", Titel + Kategorie + Zeitstempel
  • Quiet Home Footer: Energie-Status-Text + Link, kein Strip
  • Utility Links: Kontakte, Dokumente, Abstimmungen, Einstellungen, Hilfe
📄 HTML 🖼️ PNG

Mobile Komposition

390 × 844

Eine mobile Komposition der gleichen Blöcke: Task Card mit primärem Anliegen, Count Tiles, Events-Liste (erste 2 + "Alle anzeigen"), Aushang-Liste (erster + Details-Toggle). Unten: "Anliegen melden" FAB + Tab-Navigation (Haus, Aushang, Termine, Mehr).

Mobile (390 × 844)

Kernelemente

  • Greeting: "Hallo Frau Bachmeier" + Datum
  • Task Card: "Jetzt zu erledigen" Eyebrow + Titel des wichtigsten Anliegens + Beschreibung + "Anliegen ansehen" Button
  • Count Tiles: 3 × Kachel (Anliegen, Termine, Aushang) mit großer Zahl + Label
  • Nächste Termine: 2 Termine mit Datums-Chip, Titel, Uhrzeit, Ort, Chevron
  • Am Aushang: Erster Beitrag sichtbar, dann "Alle 3 Beiträge" Details-Toggle
  • Thumb Zone: "Anliegen melden" FAB (gold) + 4 Tabs (Haus active, Aushang, Termine, Mehr)
